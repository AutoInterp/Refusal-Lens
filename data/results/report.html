1. Overview & Experimental Setup

This research investigates how a language model decides to refuse harmful prompts at the circuit level, using mechanistic interpretability techniques on Gemma-3-4B-IT.

The pipeline follows four sequential steps:

  1. Refusal Direction Computation — Identify direction vectors separating harmful from harmless activations
  2. Attribution Circuit Analysis — Trace token-level contributions to the refusal direction
  3. Supernode Analysis — Map features to interpretable semantic concepts via Neuronpedia
  4. Jailbreak Testing — Test model robustness against adversarial prompts

Key Definitions

TermDefinition
Separation Score mean(harmful_projections) - mean(harmless_projections) along the refusal direction. Higher = better discrimination between harmful and harmless prompts at that layer.
Refusal Direction A unit vector in d_model-dimensional space computed as r_l = normalize(E[x_l | harmful] - E[x_l | harmless]).
Attribution Score (token) Dot product of a token's activation vector with the refusal direction. Positive = pro-refusal, negative = anti-refusal.
Attribution Score (dimension) Contribution of one hidden-state dimension: mean_activation[i] × refusal_direction[i]. Element-wise decomposition of the dot product.
Dimension (formerly "Feature") A raw index (0–2559) in the model's hidden-state vector. Not an interpretable SAE feature. "Dimension 443" = hidden_state[443].
Supernode A cluster of neurons (from Neuronpedia) sharing semantic features (e.g., "jailbreak", "harmful").
Steering Vector A direction in activation space that modulates a supernode's behavior. L2 magnitude indicates intervention strength.

2. Critical Methodological Fix: BOS Token Exclusion

BUG Discovery: BOS Token Artifact The BOS (Beginning of Sequence) token at position 0 had an attribution score of 218,963.39 — a value that was identical across all 20 prompts (harmful and harmless). This is not a refusal signal; it is an attention sink artifact that inflated all analyses by ~35%.

What Was Wrong

IssueImpact
BOS token (position 0) included in attribution averages Mean inflated from 12,741 to 19,776 (+55%)
Feature attributions used torch.abs() Lost sign information — anti-refusal features appeared as pro-refusal
Previous conclusion: "refusal decided at position 0" Incorrect — BOS value is a constant, not discriminative

INSIGHT Dimension 443: Dominant Refusal Signal A single hidden-state dimension (index 443) accounts for 99%+ of dimension-level attribution across ALL prompts. Its score varies by prompt (30,300–46,819) but it is always present. Caveat: this is a correlation finding (largest element-wise product), not a proven causal gate. Ablation experiments (zeroing dimension 443) are needed to confirm whether it actually controls refusal behavior.
INSIGHT Dimension 1209: The Anti-Refusal Signal Dimension 1209 consistently has negative attribution (-10 to -21), meaning it actively pushes against the refusal direction. Before our fix (when abs() was used), this dimension would have incorrectly appeared as pro-refusal. The interplay between Dimension 443 (+) and Dimension 1209 (-) may constitute the core refusal/compliance decision mechanism.

Refusal Pipeline Architecture

The four supernodes form a coherent processing pipeline:

StageSupernodeFunctionEvidence
1. DetectSupernode 1 Classify input as harmful/dangerous/illegal 8 neurons, features: harmful, dangerous, illegal, prohibited, unsafe
2. AssessSupernode 2 Evaluate if safe response is possible 5 neurons, acts as counterbalance (helpful, safe, constructive)
3. ExecuteSupernode 3 Generate refusal/denial response 4 neurons, no steering vector — downstream executor only
4. GuardSupernode 4 Detect jailbreak/bypass attempts 10 neurons, strongest steering vector (2.31)
Figure 5: Feature distribution across supernodes. X-axis: semantic feature labels from Neuronpedia. Y-axis: number of neurons tagged with that feature. Bars color-coded by supernode. Security features (jailbreak, bypass, exploit) each appear 3 times, dominating the distribution.
Figure 6: Steering vector statistics. Top-left: L2 norm (magnitude) — higher = stronger intervention potential. Top-right: mean vs. std of vector components — high std = concentrated steering. Bottom-left: min/max component values. Bottom-right: number of active dimensions. Supernode 4 (Security) has the strongest magnitude (2.31).
INSIGHT Refusal is Security, Not Ethics The dominant features are jailbreak, bypass, and exploit — not ethical concepts like "wrong" or "immoral." The model has learned refusal as a pattern-matching defense against known attack vectors, not as principled ethical reasoning. This implies that novel attack patterns not matching known security features may bypass the refusal circuit entirely.
INSIGHT Supernode 3 Cannot Be Steered Directly The Refusal Execution supernode (3) has no steering vector, meaning it cannot be directly modulated. To change refusal behavior, intervention must target upstream decision-makers: Supernode 1 (what counts as harmful), Supernode 2 (what counts as safe), or Supernode 4 (what counts as a jailbreak).

Key observations from the comparison (after BOS exclusion):

  • Average attribution varies modestly across prompts. Shorter prompts show higher per-token averages because attention is concentrated over fewer tokens.
  • There is no clear separation between harmful (red) and harmless (blue) prompts in raw attribution magnitude, supporting the finding that the refusal direction captures a general processing axis.
  • Token count ranges from 5 to 23, with harmful prompts tending to be slightly longer.

Primary Findings

#FindingEvidence
1 BOS token is a universal artifact, not a refusal signal Identical value (218,963) across all 20 prompts, zero variance, 9x content ratio
2 Layer 9 shows strongest separation (2,340), not the final layer Bimodal pattern with secondary peak at layer 15 (1,984)
3 Dimension 443 dominates the refusal dot product 99%+ of dimension-level attribution, present in 100% of prompts, scores 30K–47K. Causal role unconfirmed (needs ablation).
4 Dimension 1209 actively opposes refusal Consistently negative scores (-10 to -21), discovered only after fixing abs() bug
5 Refusal circuitry is fixed, not prompt-dependent Same top-5 features across harmful and harmless prompts
6 Refusal is encoded as security, not ethics Dominant features: jailbreak (3), bypass (3), exploit (3)

Interesting Observations

Harmless prompts can have higher attribution than harmful ones. The highest non-BOS attribution belongs to "Benefits of studying a foreign language" (25,572), while the lowest belongs to "Steal enriched uranium" (23,127). The refusal direction captures content-processing magnitude, not binary intent.
The refusal circuit is always running. The same dimensions (443, 1698, 1365, 1209, 1980) appear for both harmful and harmless prompts. The circuit doesn't activate on demand — it runs continuously, and its output determines the refusal/compliance decision downstream.
Dimension 443 varies by prompt, even though it always dominates. Its score ranges from 30,300 (uranium theft) to 46,819 (joining clubs). This variation — higher for shorter, simpler prompts — may reflect attention concentration: fewer tokens mean more attention weight per token, amplifying dimension projections.

Recommended Next Steps

  1. Complete all 16 layers (8–23) to map the full separation profile and confirm the bimodal hypothesis
  2. Investigate Dimension 443 using Neuronpedia or activation patching to understand what it represents semantically
  3. Run ablation experiments: zero out Dimension 443 and measure impact on refusal behavior
  4. Compare signed attributions between harmful and harmless prompts to find differentially-activating dimensions

  6. Test Dimension 1209 amplification: if it opposes refusal, amplifying it might suppress refusal for harmful prompts
